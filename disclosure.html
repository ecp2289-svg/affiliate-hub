제휴 링크와 글 운영 방식

이 사이트는 본문을 경고문처럼 만들지는 않지만, 실제 제휴 링크가 들어가는 경우 해당 링크 주변에 알아볼 수 있게 표시합니다.

기본 원칙

  • 승인되지 않은 프로그램 링크는 실제 제휴 링크처럼 넣지 않습니다.
  • 직접 확인하지 않은 내용을 실제 사용 후기처럼 쓰지 않습니다.
  • 가격, 재고, 배송, 환불, 보상 조건은 바뀔 수 있어 공식 페이지를 우선합니다.
  • 외부 사이트에서 이루어지는 결제, 가입, 개인정보 입력, 상담, 환불은 해당 사이트 정책을 따릅니다.

표시 방식

실제 제휴 버튼이나 링크가 들어가면 링크 주변에 ‘제휴 링크’, ‘파트너스 링크’처럼 짧게 표시합니다. 글 하단에도 경제적 이해관계 가능성을 작게 남깁니다.

쓰지 않는 표현

“무조건 지급”, “확정 수익”, “누구나 가능”, “최저가 보장”, “효과 보장”처럼 조건을 단정하는 표현은 쓰지 않습니다.
